# Repository presentation / GitHub About settings

The README, source package, v0.1.0 GitHub pre-release and project metadata are
managed separately. **Editing this file does not automatically change
GitHub's About panel.** The repository owner must set these values through
the GitHub website (unless an authorized repository-settings connector is
available).

## Suggested About content

**Description**

> Offline RAG retrieval evaluation and regression testing in Python. Precision, Recall, MRR, NDCG, TREC, FAISS and reproducible SciFact benchmarks.

**Website**

https://github.com/ilker-Akbal/openrag-bench/releases/tag/v0.1.0

**Topics** (GitHub search tags)

`rag`, `retrieval`, `information-retrieval`, `evaluation`, `benchmark`,
`faiss`, `bm25`, `python`, `nlp`, `machine-learning`

This description states actual capabilities and avoids unsupported download,
external-maintainer, production-readiness, or OpenAI endorsement claims.

## How the owner applies it

1. Open https://github.com/ilker-Akbal/openrag-bench
2. In the **About** panel, select the gear/edit control.
3. Paste the description, release URL, and the 10 topics above.
4. Save and confirm the About panel reflects them.
5. Under **Settings → General**, keep **Issues** enabled.
6. Under **Settings → Security → Code security and analysis**, enable private
   vulnerability reporting if it is available for this repository.
7. GitHub Discussions is optional; for a new, lightly used project, use
   Issues to avoid scattering real feedback across empty channels.
8. Wiki is optional; the project already maintains documentation in `docs/`,
   so leaving the wiki unused (or disabling it) avoids conflicting versions.
