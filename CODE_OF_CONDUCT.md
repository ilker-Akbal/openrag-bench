# Community Code of Conduct

OpenRAG Bench welcomes feedback and contributions from people of different
backgrounds and experience levels. We aim for a technical community where
questions, reproducible bug reports, and respectful disagreement are welcome.

## Expected behavior

- Be respectful and considerate in issues, pull requests, and discussions.
- Challenge technical claims with evidence and reproducible examples, not
  personal attacks.
- Respect other developers' time: provide clear steps, versions and labels.
- Credit original authors, maintain dataset provenance, and comply with
  copyright and license requirements.
- Protect privacy: do not post credentials, personal information, private
  questions, or proprietary document excerpts.

Harassment, discriminatory abuse, intimidation, spam and deliberate exposure
of personal/private information are not acceptable.

## Scope and moderation

This code covers project-managed public and private GitHub interactions.
The project maintainer may edit, lock, or remove abusive contributions and
limit participation when necessary. Enforcement decisions should be
proportionate and consistently applied.

For public project conduct problems, use GitHub's content-reporting controls
on the affected discussion or comment, and refrain from escalating publicly.
For sensitive concerns, contact the repository maintainer through a
private contact method listed on the maintainer's GitHub profile, if one
is available. If not, use GitHub's abuse/reporting channels rather than
publishing personal details. Security vulnerabilities follow
[SECURITY.md](SECURITY.md), not this process.
